# Space assets
- Landsat 8: NASA 3D Resources, https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Landsat%208 — public domain, free and without copyright per repository README.
- Earth surface and cloud maps: NASA Blue Marble maps distributed in Three.js examples, https://threejs.org/examples/textures/planets/ — NASA public-domain Earth imagery.
- Earth night lights: NASA imagery distributed via Three.js examples, https://threejs.org/examples/textures/planets/earth_lights_2048.png — NASA public-domain imagery.
- Mumbai-inspired landscape: AI-generated conceptual demonstration, not satellite imagery or a scientific dataset.
- Satellite antenna: procedural illustrative NISAR-inspired mesh attached to the NASA Landsat reference model; not an accurate NISAR spacecraft model.
